Layout

Thirteen page layouts, all built on one page grid: content, wide and full column lines, plus an optional sidebar. Open each for a working example, using generated demo images and video.

Cover

A full-screen image or video first; the nav floats over it and turns to glass on scroll. Homepage, feature posts, project landings.

Reading

One reading column; figures break out to wide or full. Normal blog posts.

Sidebar

Text with a sticky table of contents. Docs, the notebook, long posts, the resume.

Margin notes

Footnotes beside the text, tap-to-open on phones. Long writeups, investigation notes.

Split

Text on one side, a visual on the other, then alternating feature rows. Project landings.

Grid

A filterable grid of cards. Projects, photos, blog cards, tag pages.

List

A dense list grouped by year, searchable. Archives, link collections, search results.

App

The content fills the window; the nav shrinks to one pill. Games, demos, tools.

Story

A pinned visual that changes as the steps scroll by. Explainers, project tours, films.

Empty

A short message with a cat. 404, no results, offline.

Panels

Full-page images or videos with brief text; each scroll moves one whole page. Launches, showcases.

Deck

One stage; each scroll is the next slide, and pieces glide between slides. Talks, explainers.

Resume

A header card, a sticky section index and a timeline; prints as one clean column.
