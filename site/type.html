Red Dot Tracker

Type

Source Serif 4 with Noto Serif SC for headings, Geist for text and UI, Geist Mono for code. Chinese body text downloads no font and uses the system's built-in ones. Every font is self-hosted with the site. Switch EN / 中文 in the toolbar to see both languages.

Three roles

Headings
Source Serif 4
Chinese headings: Noto Serif SC, loaded in slices on demand.
Text and UI
Geist
Chinese body: PingFang, Microsoft YaHei and friends, nothing to download.
Code
Geist Mono
Terminals, commands and inline code.

Scale

Seven sizes that scale smoothly with the viewport. Chinese gets a 1.8 line height, no letter spacing, and can break between any two characters.
