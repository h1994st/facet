Color

The palette is small and every color is muted. The accent is the only colorful thing on a site; everything else is a cool gray. Use the dots in the toolbar to change the accent of the whole reference site.

Accents

Eight hues at OKLCH L 0.76 / C 0.06 on dark and L 0.52 / C 0.07 on light. Equal lightness means buttons and links have the same contrast on every site (about 9:1 on dark and 5:1 on light). Graphite is a near-neutral extra. The ratios are against the page background.

Near-neutral accents

When the hues run out, add near-neutrals: the same lightness (so the same contrast) at C 0.02 (0.025 on light), nearly gray. Keep them at least 70° apart or they become hard to tell apart.
