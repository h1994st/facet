Layout

Page layouts, all built on one page grid: content, wide and full column lines, plus an optional sidebar. Open each for a working example, using generated demo images.

Reading

One reading column; figures break out to wide or full. Normal blog posts.

Docs

Text with a sticky table of contents. Docs, the notebook, long posts, the resume.

Margin notes

Footnotes beside the text, tap-to-open on phones. Long writeups, investigation notes.

Split

Text on one side, a visual on the other, then alternating feature rows. Project landings.

Grid

A filterable grid of cards. Projects, photos, blog cards, tag pages.

List

A dense list grouped by year, searchable. Archives, link collections, search results.

Resume

A header card, a sticky section index and a timeline. Prints as one plain column.

Cover

An image or video fills the first screen; the nav is clear, then glass. Homepages, feature posts.

Story

A pinned visual that changes as the steps scroll past. Explainers, project tours.

Panels

Each scroll snaps to the next full page and its text arrives. Launches, showcases.

Deck

One stage; every scroll or arrow key is the next slide, and the pieces glide. Talks.

App

The content fills the window; the nav shrinks to a corner pill. Games, demos, tools.

Empty

A short message with a cat. 404, no results, offline.

Focus

A centered page about one thing: contact, a link hub, a launch page.
